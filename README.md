# Mis apuntes y práctica de SQL

Este repositorio guarda mi material de estudio del curso **"SQL TOTAL - Domina Bases de Datos de 0 a Avanzado en 12 Días"**. Lo uso como respaldo personal de mis apuntes y de los ejercicios que voy practicando.

## ¿Qué hay aquí?

- **`guia_sql_unificada.md`** — Mi guía de estudio con todos los temas que he visto en el curso: consultas básicas, filtros, funciones de agregación, JOINs, subconsultas, funciones de ventana, procedimientos almacenados, transacciones, y más. También incluye una lista de mis errores más comunes para no repetirlos.

- **`ejemplos_sql/`** — Los scripts de dos bases de datos de ejemplo que uso para practicar:
  - `Netflix_schema.sql` y `Netflix_data.sql`: una base de datos con series, episodios y actores, para practicar consultas de todo tipo.
  - `EmpresaDB_schema.sql` y `EmpresaDB_data.sql`: una base de datos de una empresa (departamentos, empleados, proyectos), que uso sobre todo para practicar procedimientos almacenados y transacciones.

## ¿Para qué sirve este repositorio?

Es un espacio personal de aprendizaje, no un proyecto de trabajo en equipo. Lo uso para tener mis apuntes organizados y accesibles desde cualquier lugar mientras avanzo en el curso.
